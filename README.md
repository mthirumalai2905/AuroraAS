# AuroraAS

Marketing site and stakeholder portal for Aurora AS, a Nordic finance and equity group.

Built with Next.js 16 (App Router), React 19, Tailwind CSS v4, Motion and Lenis.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
